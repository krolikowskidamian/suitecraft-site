# Product screenshots

Captured from the real SuiteCraft interface through the permanent SuiteCraft Lab scenarios. `demo.html?step=N` presents these images as a deterministic product tour. All visible account, object ID and value examples are fictional and contain no client information.

Tour images use a consistent 1440×1000 landscape canvas. Run `npm run marketing:screenshots` from the extension repository to refresh them. The command opens isolated, headless Brave sessions and writes the current product scenes directly into this directory.

Refresh only the affected images after a UI change. Product version labels and test-environment badges are intentionally hidden in marketing captures so routine releases do not make otherwise current screenshots look stale.

Do not replace these files with captures from a client account unless all customer data and account identifiers have been removed and the result has been reviewed before publication.
