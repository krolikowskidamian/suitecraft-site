# Synthetic screenshots

Captured from the real SuiteCraft interface running with synthetic fixtures. `demo.html?step=N` presents these images as a deterministic product tour. Every visible account, object ID and value is fictional.

Tour images use a consistent 1440×1000 landscape canvas. The original portrait popup capture is retained in `source/01-quick-access-portrait.png`; `01-quick-access.png` is its presentation-ready landscape composition.

Do not replace these files with captures from a client account unless all customer data and account identifiers have been removed and the result has been reviewed before publication.
