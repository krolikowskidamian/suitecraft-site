PRODUCT CHANGELOG · BETA CHANNEL

Release history.

New features, improvements and fixes in every SuiteCraft release. The current version is expanded below; choose an earlier version to see its details.

CURRENT RELEASE0.4.1SuiteCraft Search, clearer Change Plans and faster sync modesOctober 8, 2026

New

  • SuiteCraft Search brings Menu, This page and Workspace together in All, with separate scopes and filters for Favorites, Catalogue and List values.
  • Menu results show matching destinations with their full navigation path and type. Current-page fields can be found by label or field ID, then located on the form or copied by ID. Empty All and Menu searches show no result tree.

Improved

  • Go to record remains directly beside the search input and carries the entered ID into the record finder. All shows up to three results per source, with Show all opening the relevant scope.
  • Change Plans have clearer summaries, progress and action menus, expandable descriptions and notes, and an Example item status for test cases and supporting references.
  • Synchronization offers Default, Quick, Quickest and experimental Turbo modes, with bounded parallel requests, retry backoff and session timing comparisons.

Fixed

  • Saved Search links open the definition consistently from Quick find record, Favorites and Change Plans while preserving existing favorite and plan-item identities.
  • Parallel synchronization retains deterministic snapshot order and never publishes an incomplete list after failed requests, cancellation or an account or role change.
EARLIER RELEASE0.4.0Quick find record, account management and clearer Quick AccessOctober 6, 2026

New

  • Quick find record opens NetSuite records from the popup using a type and Internal ID, exact name or supported Script ID. Custom record entries support a numeric type ID or a synchronized type Script ID.
  • Manage accounts and roles in Workspace: rename local labels and remove downloaded data for a selected account or role. Account identities remain unchanged, and Favorites and Change Plans are retained.

Improved

  • Go to record sits beside Quick Access search and carries the entered ID into the record finder. Full catalogue results open in Workspace with the search text, object filter, account and role preserved.
  • Quick Access keeps empty result groups on one line, identifies Add to Favorites with a star and provides a compact refresh action for local results.
  • Standard Lists is a separate synchronization category, unselected by default. Download Subsidiaries, Locations, Departments, Classes and Currencies when you choose it.

Fixed

  • Synchronization retries transient server failures on the failed page and retains previous snapshots if the download cannot finish. List progress messages show actual counts instead of unresolved placeholders.
  • Unavailable NetSuite list APIs now produce one actionable message. Older open tabs explain when a refresh is needed instead of silently skipping Standard Lists.
  • Dark mode keeps embedded NetSuite shortcuts and popups in their light appearance. Page button detection has a fallback for pages without the expected NetSuite loader.
  • Quick find record opened from a page shortcut can read the current NetSuite origin when Chrome does not expose the tab URL, avoiding the Invalid URL error.
EARLIER RELEASE0.3.0Reference lists, filtered Quick Access and a refreshed popupSeptember 30, 2026

New

  • Synchronize Subsidiaries, Locations, Departments, Classes and Currencies with the main catalogue, and browse their values and Internal IDs in Lists.
  • Select Custom Lists from the catalogue or add custom records as reference lists using a Script ID or Internal ID, with name or a custom field as the label.
  • Search saved list values from the NetSuite navigation menu and extension popup, copy IDs and open records.

Improved

  • Quick Access separates Favorites, Catalogue and List values, with filters for object types and individual lists.
  • List synchronization includes search by name or ID, selected lists first, compact rows and editable configurations included in local backups.
  • Choose light or dark mode across SuiteCraft. Settings include expandable feature descriptions, screenshots and field help; feature switches change only through their toggle.

Fixed

  • Corrected links for standard reference lists and custom record entries, including configurations that use only a Script ID.
  • Unavailable lists do not stop the remaining synchronization, and failed downloads retain the previous local copy.
EARLIER RELEASE0.2.3Quick Access in NetSuite and Excel exports across WorkspaceSeptember 23, 2026

New

  • Change Plan items now use To create, To update, To delete, Needs attention, Completed and Excluded. Needs attention is the default; Markdown groups items by action and includes Code / delivery / PR links.
  • Quick Access in the NetSuite navigation bar brings account Favorites and local catalogue search together, with results opening in new tabs.
  • Choose CSV or Excel XLSX for catalogue, comparison, missing-scope, snapshot and Change Plan exports.

Improved

  • Quick Access opens on hover with search focused, preserves results while hidden and waits 500 ms after typing before searching.
  • Manual workflow and custom-record detail synchronization is available in a collapsed Advanced section.

Fixed

  • Quick Access stays in the navigation menu, respects its display scaling and accepts spaces in search queries.
  • Synchronization resets and verifies supported list filters so remembered Script Type, API Version and workflow status selections do not silently narrow downloads.

Quick Access uses local data: Favorites belong to the current account, and catalogue search is scoped to the verified account and role. Use Reload data after synchronization to refresh cached results.

EARLIER RELEASE0.2.2Template catalogue synchronization and safer object matchingSeptember 22, 2026

New

  • Synchronize customized Advanced PDF/HTML Templates and Email Templates into the local catalogue for search, comparison, exports and Change Plans.
  • Email Template synchronization covers every record type from the global list without downloading template bodies or message content.

Improved

  • Cross-account comparison uses portable Script IDs, while same-account history and record-page resolution use account-local Internal IDs.
  • Overlapping snapshots and roles are consolidated into one catalogue object, with the connected context preferred where available.
  • Change Plan readiness now distinguishes missing source data from a missing portable Script ID.
  • Overwrite latest version is enabled by default; clear it when another historical snapshot should be retained.

Template synchronization resets remembered list filters, excludes untouched NetSuite defaults and verifies completeness before replacing a snapshot.

EARLIER RELEASE0.2.1More reliable Change Plan matching and clearer release notesSeptember 18, 2026

New

  • Add to Change Plan can synchronize a single object on the spot when it isn't in your local catalogue yet, instead of requiring a full category synchronization first.

Improved

  • Release-readiness comparison now matches objects across accounts by Script ID or Internal ID alone — a differently named admin role or a differently filtered sync no longer hides a real match.
  • Custom Record Type comparisons also flag differences in their child Custom Record Fields.
  • Items that can't be automatically compared are grouped with manual review items instead of a separate blocked state that could never resolve.
  • Generated release-note Markdown is grouped by status and object type, numbered per type, and includes each object's NetSuite link.
  • Record-page shortcuts now appear on the Workflow visual editor page, and opening several inspector panels at once brings the one you click to the front.

Fixes an issue where adding an object to a Change Plan could save a different, unrelated object that happened to share a Script ID.

EARLIER RELEASE0.2.0Change Plans, release readiness and deeper record-page insightSeptember 17, 2026

New

  • Build local Change Plans for releases, tickets and migrations, then add NetSuite pages directly from the record header.
  • Compare plan objects with an exact target account and role to identify deploy, aligned, manual and blocked work.
  • Preview and copy Markdown release notes or export complete plans as CSV and JSON.
  • Inspect buttons found on a record page and resolve available workflow details in Script & Workflow Inspector.

Improved

  • Plans include searchable history, item statuses, release and technical notes, plus ticket and delivery links.
  • Inspector views now share a consistent searchable layout and automatically load workflow activity and history.
  • Record shortcuts have a more accurate live preview, contextual availability and unified movable popups.
  • An optional UI feature wraps crowded NetSuite record actions across multiple rows.

Change Plans, Favorites and their private notes remain local. Shared snapshot packages continue to exclude them.

EARLIER RELEASE0.1.3Record-page shortcuts, instant inspector reopening and clearer reportsSeptember 15, 2026

New

  • Open Record Explorer, Script & Workflow Inspector and Favorites directly from NetSuite record headers.
  • Choose title, header-action or floating placement, including the top-right or bottom-right corner.
  • Export clearer account-level comparison reports for review outside SuiteCraft.

Improved

  • Record Explorer now reopens instantly with its filters, session pins and scroll position intact.
  • Shortcut appearance and position can be adjusted with a live preview.
  • Comparison summaries focus on practical configuration changes and easier scanning.

Record data is refreshed only when you choose Reload data; closing the inspector now keeps the current session ready to reopen.

EARLIER RELEASE0.1.2Clearer inspectors, script metadata and a refined popupSeptember 10, 2026

New

  • Script synchronization now includes file metadata and groups deployments under their parent scripts.
  • Selected snapshots can be shared safely between authorized SuiteCraft users.
  • Selected catalogue objects can be refreshed without repeating a full account synchronization.

Improved

  • Record Explorer has deeper sublist discovery, compact field cards, session pins and direct definition links.
  • Script & Workflow Inspector has clearer deployment matching and presentation.
  • The popup now separates Workspace, catalogue search, Favorites, record tools and URL tools into distinct actions.

Starting with 0.1.2, SuiteCraft uses one consistent version number across the extension, release notes and downloadable packages.

EARLIER RELEASE0.1.0The first complete SuiteCraft Workspace foundationSeptember 6, 2026

Introduced SuiteCraft Workspace, local versioned snapshots, Catalogue, Favorites, Compare, synchronization, multilingual settings and the first private beta packaging workflow.
