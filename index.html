DESIGNED WITH CLIENT WORK IN MIND

Your account metadata stays with you.

SuiteCraft works through an already authenticated NetSuite browser tab. Catalogue snapshots, favorites and notes are stored locally in the browser profile and are not sent to a SuiteCraft backend.

PRODUCT CHANGELOG

What’s new
in SuiteCraft.

Major user-facing improvements are collected here. Small fixes remain part of the build without turning the changelog into a commit log.

CURRENT BETA0.1.2Clearer inspectors, script metadata and a refined popupSeptember 10, 2026
New
  • Script synchronization now includes file metadata and groups deployments under their parent scripts.
  • Selected snapshots can be shared safely between authorized SuiteCraft users.
  • Selected catalogue objects can be refreshed without repeating a full account synchronization.
Improved
  • Record Explorer has deeper sublist discovery, compact field cards, session pins and direct definition links.
  • Script & Workflow Inspector has clearer deployment matching and presentation.
  • The popup now separates Workspace, catalogue search, Favorites, record tools and URL tools into distinct actions.

Starting with 0.1.2, SuiteCraft uses one consistent version number across the extension, release notes and downloadable packages.

FOUNDATION RELEASE0.1.0The first complete SuiteCraft Workspace foundationSeptember 6, 2026

Introduced SuiteCraft Workspace, local versioned snapshots, Catalogue, Favorites, Compare, synchronization, multilingual settings and the first private beta packaging workflow.
