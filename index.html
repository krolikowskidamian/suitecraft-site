DESIGNED WITH CLIENT WORK IN MIND

Your account metadata stays with you.

SuiteCraft works through an already authenticated NetSuite browser tab. Catalogue snapshots, saved reference values, Favorites, Change Plans and notes are stored locally and are not sent to a SuiteCraft backend. Small interface preferences may sync through your browser profile.

WHAT’S NEW

Release notes

First official release, safer local data and more reliable synchronization.

SuiteCraft 1.0.0Current release · Stable channel

Released October 15, 2026

New

  • First official SuiteCraft release: record inspection, customization search, local snapshots, comparison and Change Plans in one read-only NetSuite toolkit.

Improved

  • English, Polish, Spanish and German interface text is more complete and consistent across the bundled tools.
  • JSON backups use compact files and include supported object refreshes. Optional storage details distinguish category snapshots from Custom Record field sets.

Fixed

  • Concurrent edits to Change Plans and Favorites are coordinated, and full local storage now reports a clear error without deleting existing data.
  • Large Workspace backups export supported records with empty names or unresolved reference links, preserving their data instead of failing validation.
  • Custom Record field sets are grouped by their actual scope, preventing unrelated legacy sublist filters from inflating the current snapshot count.
  • Synchronization verifies supported list filters and coordinates cancellation and checkpoint recovery across Workspace tabs, retaining previously verified snapshots when a run fails.
  • SuiteCraft Search keeps its navigation button in place when NetSuite opens native global search results.
  • Local database connections recover more safely around extension updates and explain when a Workspace page must be reopened, without resetting stored data.
